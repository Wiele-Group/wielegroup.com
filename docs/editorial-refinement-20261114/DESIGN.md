# Wiele — property-led editorial refinement

14 November 2026. User authorised implementing the preceding design critique.

## Direction

Preserve Wiele Investments, its reflective gold logo and South African roots. Global perspective. Property remains the core business. Aircraft, yachts, exotic and classic cars remain complementary categories. The recommended expression is an editorial brokerage: architectural imagery, readable practical information, a clear route to an enquiry and factual support for the offer.

## Implementation

Homepage now has six main sections:
1. Single property hero, with direct purchase and seller actions.
2. Property brief and honest current availability; residence, investment and seller paths consolidated once.
3. Why Wiele: brief, evidence and agreed next step; links to the existing method and clearly labelled illustrative information template.
4. Complementary luxury assets, grouped below the core property journey.
5. One selected property-research feature with evidence cutoff and registration requirement.
6. Direct enquiry, company email and three concise expandable answers.

Removed the hero slideshow, scene buttons, vertical rail, duplicate property cards, repeated aspirational galleries, oversized publication treatment and ten-question homepage FAQ block. The full architectural inspiration remains on /properties. The investment calculator moves to /buying. Buyer/seller, luxury asset and property onboarding routes remain intact.

Approved logo assets are unchanged. A brighter ivory/ink split hero gives the architecture a separate stage, without text over the photograph. Gold is concentrated in the identity; reading content uses charcoal and muted ink. Practical link/button/navigation type is larger across the site. Existing property and asset images retain their AI-created concept disclosures. No stock, credentials, results, offices or specialist partners are invented.

## Interaction contract

Hero → immediate property purchase/sale route → semantic link via pointer/touch/keyboard → default/focus/navigation → no animation or client state → normal browser interruption/navigation → same links on phone → no reduced-motion dependency.

Property brief → residence/investment/seller purpose → ordinary links with fixed consent-gated journey values → default/focus/navigation → no required animation → immediate navigation → same keyboard/touch actions → static fallback identical.

Answers → clarify common questions → native details/summary → closed/open → no animation → freely reversible → native keyboard/touch support → identical without JavaScript or motion.

Asset category → reach corresponding category page/anchor → ordinary link → default/hover/focus/navigation → existing restrained image hover only → normal browser handling → no hover required → reduced-motion transforms disabled.
