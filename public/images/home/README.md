# Wiele Home image manifest

The seven dedicated Home assets below are optimized WebP copies of the supplied artwork. To replace one, use published-for-web artwork with the same filename and rebuild. A missing file renders an architectural illustration without generating a failed image request. Social previews use the included editorial card.

- `hero-palazzo-twilight.webp`
- `triptych-architecture.webp`
- `triptych-maritime.webp`
- `triptych-automotive.webp`
- `dossier-cover-cape.webp`
- `dossier-cover-ligurian.webp`
- `dossier-cover-oxfordshire.webp`

Keep these images exclusive to the five Home routes and their social previews. Dossier covers represent fictional examples.
