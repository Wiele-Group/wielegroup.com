# Wiele Property identity

Created 24 October 2026 for the sales-focused Malta property-marketing platform at wielegroup.com.

## Design
A serif W within an open architectural archway, paired with an outlined WIELE wordmark and a spaced PROPERTY descriptor. The archway suggests a threshold and Mediterranean architecture; it does not depict a specific building or imitate a surveyed agency mark.

## Delivered files
- Primary horizontal SVG: forest, ivory/reversed and one-colour black.
- Architectural monogram SVG: the same three colours.
- Simplified W icon SVG: the same three colours; use for very small applications.
- Transparent primary PNG: 1480 × 480 pixels, each colour.
- SVG favicon and square PNG site icons at 16, 32, 180, 192 and 512 pixels.
- Flat preview sheet: identity-preview.svg and identity-preview.png.

SVG masters contain actual outlined paths and shapes; no external font, raster image or network dependency is required. PNG exports have transparent backgrounds except the deliberate square favicon artwork. Master source: scripts/build-property-identity.py plus the licensed typography source in this folder.

## Colour and use
- Forest: #193F35.
- Ivory: #F6F3ED.
- Black: #18201B.
- Use ivory artwork on forest/dark backgrounds, forest or black on light backgrounds.
- Allow clear space around the lockup at least equal to the cap height of the PROPERTY descriptor. On a cramped header, use the compact mark or simplified W rather than stretching the primary logo.
- Website header widths: 185 px desktop / 145 px mobile. Small icon exports provided at 16/24/32 px for review. No print or embroidery minimum is certified.
- Do not stretch, add a roof/keys, outline the wordmark, use a drop shadow or add a registered-trademark symbol.
