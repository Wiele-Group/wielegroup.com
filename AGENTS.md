# Wiele Properties website

Before every production deployment, apply and verify AEO, GEO, SEO and metadata for the final content. Keep business identity, titles, descriptions, canonical URLs, social previews, visible answers, structured data and sitemap dates consistent. Use factual scope and availability; do not invent listings, credentials, returns or testimonials. Stock and AI imagery must remain accurately labelled.

Use `npm run deploy:cf`. It builds the site, checks the resulting local HTTP pages for metadata, crawl resources, structured data, visible FAQ agreement and assets, and only then deploys. Fix failures before publishing. Preserve unrelated local changes and source brand assets.
